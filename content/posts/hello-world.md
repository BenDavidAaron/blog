Welcome to the blog.

This starter post shows the basic structure for a Hugo article. Replace this text with your own introduction.

## Add a section

Use headings to divide a long post into clear sections. Keep each section focused on one topic.

### Add a smaller section

Use smaller headings when a section needs more detail.

## Add a list

- Keep sentences short.
- Add links when they help the reader.
- Use images when they explain an idea.

For more information, visit the [Hugo documentation](https://gohugo.io/documentation/).

## Add code

Use inline code for short commands, such as `hugo server -D`.

Use a fenced block for longer examples:

```sh
hugo new content posts/my-post.md
hugo server -D
```

## Publish the post

Set `draft: false` in the front matter. Then commit and push the file to the `main` branch.
